# discordgram

> High-performance bidirectional bridge between Discord servers and Telegram forum supergroups.
> Supports deployment on **Cloudflare Workers** or as a **Standalone Daemon (recommended)** (Termux / Linux / Raspberry Pi) with 0 open ports and 0 cloud quotas.

> [!WARNING]
> **The recommended implementation is the Termux one wich im using** Check out the [Standalone Daemon Guide](standalone/README.md) for 100% outbound, unlimited synchronization without Cloudflare Durable Object limits.
